# PP-P01. Стартовий пакет

**Тема:** Середовище, інтерпретатор і базові операції  
**Час:** 2 контактні академічні години (90 хв)  
**Передумови:** PP-L01, PP-L02

Студентський комплект містить готовий [стартовий файл](student_starter.py) і [30 карток без відповідей](student_variants.json). Практична інструкція — у [студентському PDF](../PP-P01_Практична.pdf); відкрийте його та виконайте свій варіант.

Запуск:

1. Встановіть локальний Python 3.
2. У цій папці виконайте `python student_starter.py`.
3. Перенесіть дані свого варіанта у власний файл `p01_vNN.py`, запустіть його та збережіть короткий `report.md`.

Еталон і ключі збережені окремо в [teacher](../teacher/). Не додавайте до студентської здачі файли викладача, віртуальне середовище або кеші.
